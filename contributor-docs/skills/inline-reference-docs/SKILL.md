# Inline Reference Docs Skill

## Use when

A maintainer needs reviewable inline reference documentation for a frozen
repository snapshot.

## Inputs

Repository path or URL, target ref, language scope, generated/vendor
exclusions, docs destination policy, and local-only, fork, or review-branch
mode.

## Outputs

Source inventory, immutable source SHA, exact input manifest, preservation
ledger, authored additions, quarantined corrections, truth-audit results,
docs-site route map, and verification results.

## Procedure

Validate access and freeze the source. Inventory and classify paths, select
representatives, generate proposals, preserve existing comments, truth-audit
each statement, and render routes. Stop before writing until explicit output
acceptance and separate destination authorization exist.

Read the [matrix](references/language-framework-matrix.md), [rules](references/inline-comment-rules.md),
and [audit](references/truth-audit-checklist.md) progressively.
