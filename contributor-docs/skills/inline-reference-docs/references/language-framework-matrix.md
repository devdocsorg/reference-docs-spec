# Language Framework Matrix

| Language/file kind | Framework | Extensions |
| --- | --- | --- |
| TypeScript | TSDoc / TypeDoc | `.ts`, `.tsx` |
| JavaScript | JSDoc | `.js`, `.jsx`, `.mjs`, `.cjs` |
| Python | PEP 257 with Sphinx Napoleon | `.py` |
| Java | Javadoc | `.java` |
| Kotlin | KDoc | `.kt`, `.kts` |
| Swift | Swift Markup / DocC | `.swift` |
| C# | XML documentation | `.cs` |
| Go | Go doc | `.go` |
| Rust | rustdoc | `.rs` |
| C | Doxygen | `.c`, `.h` |
| C++ | Doxygen | `.cpp`, `.cc`, `.cxx`, `.hpp`, `.hh`, `.hxx` |
| Ruby | YARD | `.rb` |
| PHP | PHPDoc | `.php` |
| Scala | Scaladoc | `.scala`, `.sc` |
| Lua | LuaLS / EmmyLua | `.lua` |
| Shell | shdoc-style headers | `.sh`, `.bash`, `.zsh`, `.fish` |
| Config/env | Plain inline comments | `.env`, `.env.example`, `.yaml`, `.yml`, `.toml`, `.ini`, `.json`, `.conf` |
