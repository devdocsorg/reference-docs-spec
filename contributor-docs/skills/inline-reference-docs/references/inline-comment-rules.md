# Inline Comment Rules

- Give each documented symbol one sentence stating what it is for.
- Use idiomatic parameter, error/exception, and return tags.
- Use examples only for nontrivial strings, arrays, small objects, enums, and
  numbers.
- Do not add boolean or large composed-object examples.
- Do not add complete import/setup samples.
- Preserve true existing comments; correct only with source evidence and record
  the original location, reason, evidence, and replacement.
