# Qualcomm Preview to Approval

Validate repository, ref, authorization, and destination; freeze the source
SHA; inventory representative files; refine proposals; save durable
preferences; authorize exact staging; inspect truth and render evidence; then
accept additions and corrections separately. Keep the Qualcomm source
read-only and use a distinct proof or destination repository. The
[product workflow](../../product-docs/workflows/add-inline-reference-docs.md)
defines behavior; this tutorial does not reimplement the app.
