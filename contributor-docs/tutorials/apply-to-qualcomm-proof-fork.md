# Apply The Workflow To A Qualcomm Proof Fork

Select a public Qualcomm repository, including a `qualcomm-meta*` repository
when available. Record the source commit, fork or review branch, exclusions,
inventory, preservation ledger, truth audit, generated site, sidebar, README
link, cleanup, and proof commit. Confirm that the source repository received
no commits or branches.
