# Bootstrap A Docs Folder

Create `docs/tooling` and `docs/content`. Add the five minimum Markdown source
pages described in [the output model](../architecture/docs-site-output-model.md),
configure the documented build command, build the site, and verify that
`docs/content/index.html` exists. Add the root README file-path link before
review.
