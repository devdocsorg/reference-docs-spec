# Qualcomm Architecture Contract

The preview separates source setup, inventory, representative proposals,
refinement, approval, staged generation, output acceptance, destination write,
and handoff. Repository immutability, credential isolation, auditability,
cleanup, and production verification remain explicit architecture boundaries.
