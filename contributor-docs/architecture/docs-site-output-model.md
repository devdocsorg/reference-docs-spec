# Docs Site Output Model

Applied repositories use `docs/tooling` for Sphinx/MyST configuration and
scripts, and `docs/content` for generated HTML. The minimum source pages are
`index.md`, `overview.md`, `reference.md`, `configuration.md`, and
`api/index.md`. Every generated group must be reachable from the sidebar and
the root README must link to `docs/content/index.html`.
