# Product Documentation

Reference Docs Spec helps a contributor inspect a repository, propose inline
reference documentation, review evidence, and approve a scoped or full
documentation run.

- [Reference docs workflow](concepts/reference-docs-workflow.md) defines the
  lifecycle and approval vocabulary.
- [Add inline reference docs](workflows/add-inline-reference-docs.md) explains
  the ordinary user journey.
- [Build a static reference site](workflows/build-static-reference-site.md)
  explains the rendered output contract.
- [Qualcomm preview to approval](workflows/qualcomm-preview-to-approval.md)
  defines the accepted preview-app behavior and recovery states.
